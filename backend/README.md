# Backend Monavero

Este diretório reserva o espaço da futura API Java, prevista para a **Etapa 2** do [roadmap](../docs/ROADMAP.md).

A implementação ainda não foi iniciada. Estão planejados Java, Spring Boot, Spring Security, PostgreSQL, migrações Flyway e módulos separados por domínio bancário. As regras financeiras e as permissões reais serão validadas no servidor.

O frontend atual permanece uma aplicação demonstrativa independente; não existe API própria publicada neste estágio.
